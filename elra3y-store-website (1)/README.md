# Elra3y Store — الموقع جاهز للرفع

موقع ثابت (Static) بالكامل — HTML/CSS/JS بدون أي Backend، شغال أوفلاين تمامًا (حتى الباركود بقى مُولَّد محليًا من غير أي رابط خارجي).

## إيه اللي اتغيّر؟

1. **الباركود اتصلح نهائيًا** — كان بيعتمد على مكتبة QR من إنترنت خارجي (CDN)، ولو الشبكة بطيئة أو فيه أي حظر (زي إضافات منع الإعلانات اللي بتحظر أي حاجة اسمها `qrcode`) كان الكود مش بيظهر. دلوقتي المكتبة (`assets/qrcode.js`) بقت **مُضمّنة جوه الموقع نفسه**، بترسم الباركود فعليًا (اتعمله اختبار وطلع سليم 100%) وبتشتغل حتى من غير إنترنت خالص.
2. **الباركود بقى في لوحة الإدارة بس** (`/mano`) — تبويب جديد اسمه **"▦ الباركود"**، وفيه تحميل وطباعة، ومتاح بعد تسجيل الدخول بس زي ما طلبت.
3. **زر مشاركة جديد في الصفحة الرئيسية** — دايرة صغيرة فوق يمين الصفحة، لما تدوس عليها بتفتح قائمة فيها خيارين:
   - **مشاركة الرابط** (بتفتح شاشة المشاركة في الموبايل، أو بتنسخ الرابط لو مفيهاش دعم مشاركة)
   - **مشاركة الباركود** (بتشارك صورة QR جاهزة، أو بتنزّلها لو المتصفح مش داعم مشاركة الملفات)

## هيكل الملفات

```
index.html          → الصفحة الرئيسية (العميل)
mano/index.html      → لوحة الإدارة (كلمة المرور الافتراضية: 25817089)
assets/qrcode.js      → مولّد الباركود المحلي (أوفلاين بالكامل)
assets/store-data.js  → تخزين البيانات (localStorage في متصفح كل زائر)
assets/app.js         → منطق الصفحة الرئيسية
assets/admin.js       → منطق لوحة الإدارة
assets/style.css       → التنسيق
assets/particles.js, icons.js → تأثيرات وأيقونات
```

> ملحوظة مهمة: البيانات (الروابط، الاسم، اللوجو، كلمة المرور، الإحصائيات) متخزنة في `localStorage` بتاع متصفح كل جهاز، يعني التعديل من جهاز الإدارة مش بينتقل تلقائيًا لكل الزوار إلا لو غيّرت البيانات الافتراضية جوه `assets/store-data.js` قبل الرفع، أو ربطت الموقع بقاعدة بيانات حقيقية لاحقًا.

## الرفع على GitHub Pages (مجاني)

1. اعمل حساب على [github.com](https://github.com) لو معندكش.
2. اعمل **New repository** — اديله اسم زي `elra3y-store` واختار **Public**.
3. ارفع كل ملفات الموقع (اللي جوه الفولدر ده) على الـ repo، إما:
   - عن طريق السحب والإفلات في صفحة الـ repo على GitHub ("Add file" → "Upload files")، أو
   - عن طريق git من جهازك:
     ```bash
     git init
     git add .
     git commit -m "Elra3y Store"
     git branch -M main
     git remote add origin https://github.com/USERNAME/elra3y-store.git
     git push -u origin main
     ```
4. من إعدادات الـ repo: **Settings → Pages**.
5. تحت **Build and deployment** اختار **Source: Deploy from a branch**، وبعدين اختار **Branch: main** و **Folder: / (root)**، ثم **Save**.
6. بعد دقيقة أو اتنين هيظهرلك رابط الموقع تحت في نفس الصفحة، شكله هيكون:
   `https://USERNAME.github.io/elra3y-store/`

## الرفع على استضافة تانية (Netlify / Vercel / أي استضافة عادية)

الموقع مفيهوش أي build step — تقدر ترفع الفولدر زي ما هو مباشرة:
- **Netlify**: اسحب الفولدر كامل في [app.netlify.com/drop](https://app.netlify.com/drop).
- **Vercel**: `vercel deploy` من داخل الفولدر (أو من الواجهة، ارفع الفولدر كـ "Other" framework).
- **أي استضافة بتدعم ملفات HTML عادية** (Hostinger, cPanel, إلخ): ارفع كل حاجة جوه فولدر `public_html` أو الفولدر الرئيسي للموقع.
